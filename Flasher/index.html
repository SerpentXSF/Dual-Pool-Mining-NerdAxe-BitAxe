Notes

    
    
      
  • Requires Chrome or Edge on desktop, served from http://localhost (run python serve.py). Web Serial does not work from file:// or in Firefox/Safari.
    • 
      
  • Use the device's USB (USB-JTAG/serial) port. If the port isn't listed, install the USB-serial driver for your board.
    • 
      
  • Merged factory images flash at 0x0. If you only have a plain app firmware.bin, flash it at 0x10000 (and bootloader at 0x0, partitions at 0x8000 separately).
    • 
      
  • Stuck at connect? Hold BOOT, tap RESET, release BOOT to enter download mode, then retry.
